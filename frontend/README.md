# Atlas frontend / Atlas 前端

React + Vite + Tailwind 4 with official shadcn/ui components. The agent controllers and FastAPI API retain their existing responsibilities. See [frontend integration](../docs/frontend-ui.md) for the rendering contract, build instructions, and verification.

采用 React、Vite、Tailwind 4 与官方 shadcn/ui 组件。Agent 控制器与 FastAPI API 保留原有职责。渲染约定、构建说明及验证见[前端整合说明](../docs/frontend-ui.md)。

```sh
pnpm install --frozen-lockfile
pnpm build
```
