# Demo Readings / 内置试用材料

New material offers a demo selector alongside paste and file upload. Choose a reading, click **Use this material**, review or edit its full text, then click **Explore this reading**. The selected learning mode and AI option still apply. Unlike the small home-page sample, these submissions enter browser History and support Guided study and Saved normally. Loading a reading alone does not analyze it or call AI.

New material 提供案例选择器，并保留粘贴和文件上传。选中材料后点击 **Use this material**，查看或编辑全文，再点击 **Explore this reading**。所选学习模式和 AI 选项仍然生效。与主页短示例不同，这些提交正常加入浏览器 History，并支持 Guided study 和 Saved。仅加载材料不分析，也不调用 AI。

The ten English text files are bundled in `data/demo-materials/`; the application does not depend on the original Windows folder. Text and attribution headers are copied intact, including source URLs, authors, licence details, access dates, level and conversion notes. They are introductory university textbook excerpts, not reviewed secondary-school teaching materials. The full text, including attribution headers, is loaded for analysis; displayed word counts include those headers. The manifest provides public metadata; the detail endpoint accepts only manifest identifiers.

十份英文文本内置于 `data/demo-materials/`，运行不依赖原始 Windows 文件夹。全文与归属声明完整复制，包括来源链接、作者、许可、访问日期、程度和转换说明。这些是大学入门教材摘录，尚未经中学课程审核。分析时加载包含归属声明的完整文本，显示词数也包含声明。清单接口提供公开元数据，详情接口仅接受清单中的标识。

文件保留原有 Creative Commons Attribution-NonCommercial-ShareAlike 4.0 归属和许可链接。本课堂原型保持每份材料与归属声明相连。
